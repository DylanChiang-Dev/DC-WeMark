# Surface: 編輯器主畫面（web/index.html）

Mode: Operate。使用者：以簡體中文為主的公眾號 Markdown 寫作者，桌機長時間寫作，手機偶爾查看。任務：寫／匯入 → 預覽 → 調設定 → 複製。限制：純前端、無外部字體或請求、文章輸出主題本輪不動；介面文案改為簡體。

## Direction contract

THESIS: 編輯器是一張朱絲欄信箋，寫公眾號就是寫給讀者的一封信；拒絕「白卡片＋藍色主按鈕」的 SaaS 預設與暗色程式碼編輯器的反向預設。

OWN-WORLD: 天青灰色箋外圍、白箋編輯區、墨色文字；朱紅只用於四處：每行朱絲欄、印章（複製）、選中狀態、分隔線握把。頂欄底邊為一粗一細文武線。標誌為白文方印「记」。品牌字與面板標題用系統宋體，介面用系統黑體。

STORY: 使用者一眼認出這是排版寫作工具；在信箋上寫，右側看到成品；按下方印即複製，落款鈐印確認完成，知道文章從未離開本機。

FIRST VIEWPORT: 單列頂欄：左印章標誌＋宋體 DC-WeMark；中段手機／寬版切換；右側匯入、匯出、设置（線性圖示＋字）與朱紅方印「复制到公众号」。下方左右雙欄：左為行高對齊朱絲欄的編輯區，右為天青底上的箋框手機預覽。狀態列以實線／虛線表示草稿狀態。手機版頂欄壓成一行，編輯／預覽切換。

FORM: 朱絲欄箋（八行箋），自有清單第 5 位；seed key 5ba7af19。吸收：Saville（同物不重複標示）、光譜線（狀態以線形表達）、單色產品頁（強調色限四處）。招牌動作：複製即落款鈐印。
