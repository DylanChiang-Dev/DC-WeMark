# 舊文稿相容：`:::` 容器語法

DC-WeMark 目前以標準 Markdown 作為唯一公開的寫作入口。早期版本曾提供
`:::` 容器語法作為進階版式（提示框、卡片、金句等），其語法借鑑 Pandoc /
markdown-it 的 fenced div 慣例。

這項能力現在僅為避免舊文稿內容損壞而保留：介面不再提供插入入口，也不再新增或
維護新的擴充模組。新文章請使用標題、引用、清單、表格等標準 Markdown 語法。

## 基本用法

```
::: note
這是一段提示內容，內部照常支援 **Markdown**、清單、連結。
:::
```

- `::: 名稱` 開啟一個容器，單獨一行的 `:::` 關閉它。
- 容器內部是正常的 Markdown，會被完整解析。
- 忘了關閉也沒關係：渲染時會在文末自動補上，並不會吞掉內容。

## 舊版內建模組

| 名稱 | 用途 | 外觀 |
|---|---|---|
| `note` / `info` | 資訊提示 | 藍色左邊條 + 淡藍底 |
| `tip` / `success` | 要點 / 成功 | 綠色左邊條 + 淡綠底 |
| `warn` / `warning` | 警告 | 琥珀色左邊條 + 淡黃底 |
| `danger` / `error` | 危險 / 禁止 | 紅色左邊條 + 淡紅底 |
| `card` | 卡片 | 白底 + 邊框 + 圓角 |
| `quote` | 金句 | 主題強調色左邊條 + 淡底 |
| `timeline` | 時間軸 | 主題強調色左側直線（內放清單） |

語義提示框（note/tip/warn/danger）用固定語義色，跨主題一致；card / quote /
timeline 用當前主題的強調色，會隨主題與自訂強調色變化。

## 巢狀

容器可以巢狀，靠開閉配對：

```
::: card
### 卡片標題

::: tip
卡片裡的提示。
:::

:::
```

## 注意

- 程式碼圍欄（```` ``` ````）內的 `:::` 會原樣保留，不會被當成容器。
- 名稱只取第一個詞、僅保留英數與 `-`，其餘忽略；未知名稱會套用一個通用外殼。
- 所有輸出都是 inline style 的 `<section>`，貼進公眾號編輯器保留樣式。
